# Rahul Goud Mogili — Personal Portfolio v1

Static HTML/CSS/JavaScript portfolio, designed for GitHub Pages.

## Preview
Open `index.html` in a browser. No build process or paid service is required.

## Publish free with GitHub Pages
1. Create a public GitHub repository (for a personal root URL, name it `<your-username>.github.io`).
2. Upload `index.html` and `.nojekyll` to the repository root.
3. In Settings → Pages, choose Deploy from a branch, main, / (root).
4. Visit the URL GitHub displays.

## Maintain
Edit the `items` JSON embedded near the end of `index.html` to update the live portfolio. `portfolio.json` is a human-readable content backup; changes to that file alone will not update the website.

## Before publishing
Review the public content, especially historic metrics, ownership descriptions, product links, certifications, role titles and NDA-sensitive material. No unpublished product name or internal trial figures are included. No CV PDF, address, birth date or private project document is published.
